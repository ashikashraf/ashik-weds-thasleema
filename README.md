# Digital Wedding Embrace

Create a **beautiful, elegant, interactive wedding reception invitation website** based on the uploaded wedding invitation image. Use the image as the **primary visual reference for the design, typography, floral elements, illustrations, spacing, and color palette**.

The website should feel like a **premium digital wedding invitation**, not a generic event website. The overall aesthetic should be **romantic, sophisticated, minimal, Islamic-inspired, and luxurious**, while remaining easy to navigate on mobile.

### 1. Design & Color Theme

Use the uploaded invitation as the visual design reference.

Primary visual style:

* Warm ivory / cream background

* Muted sage green

* Olive and eucalyptus green

* Champagne / antique gold

* Soft beige

* Dark olive/charcoal text

* Subtle floral illustrations

* Elegant botanical borders

* Fine gold ornamental lines

* Cream-colored roses

* Soft shadows and subtle gradients

The design should closely resemble the invitation's aesthetic without simply placing the invitation image as the website background.

Use:

* Elegant serif fonts for headings

* Sophisticated script/calligraphy-style font for names and special headings

* Clean serif/sans-serif font for body text

* Gold decorative dividers

* Floral corner decorations inspired by the invitation

* Smooth rounded elements where appropriate

Avoid:

* Bright colors

* Heavy animations

* Modern corporate styling

* Excessive cards

* Neon colors

* Overly complicated layouts

The website should feel **timeless and luxurious**.

# 15. Mobile Experience

The website must be **mobile-first and fully responsive**.

Most guests will likely open the invitation on their phones.

On mobile:

* Hero should fit beautifully within the screen

* Names should remain readable

* Couple illustration should resize properly

* Buttons should be large enough to tap

* RSVP form should be easy to use

* Countdown should remain readable

* Maps should work properly

* Navigation should be simple

Do not allow horizontal scrolling.

# Important Design Direction

**The uploaded wedding invitation should be the main source of truth for the visual design.**

Do not create a generic wedding website.

The final website should feel like the **printed invitation has been transformed into an elegant, immersive digital experience**.

Maintain the same:

**cream + sage green + muted gold + botanical floral + elegant typography + Islamic wedding aesthetic.**

The result should feel **luxurious, romantic, warm, personal, and sophisticated**, with interactive elements that enhance the invitation rather than distract from it.

Use the actual names and event details from the provided invitation image.
